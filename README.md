# Smart Budget Planner (50/30/20)

Ένα ολοκληρωμένο, modular project για τη διαχείριση εσόδων και εξόδων βασισμένο στον κανόνα 50/30/20 (Needs/Wants/Invest).

## Δομή Project
Το project έχει χωριστεί σε ξεχωριστά αρχεία για εύκολη συντήρηση και μελλοντικές επεκτάσεις:

- `index.html`: Η κεντρική δομή της σελίδας (HTML5).
- `css/style.css`: Τα στυλ της εφαρμογής, σχεδιασμένα με CSS Variables για εύκολη αλλαγή χρωμάτων/themes.
- `js/app.js`: Η λογική της εφαρμογής γραμμένη σε Object-Oriented JavaScript.
- `README.md`: Αυτό το αρχείο.

## Εγκατάσταση & Χρήση
1. Κάντε εξαγωγή (unzip) το αρχείο.
2. Απλά ανοίξτε το αρχείο `index.html` σε οποιονδήποτε σύγχρονο web browser (Chrome, Firefox, Safari, Edge). 
3. Δεν χρειάζεται εγκατάσταση κάποιου server (π.χ. Node.js ή XAMPP), λειτουργεί άμεσα.
4. Τα δεδομένα σας αποθηκεύονται τοπικά στον browser σας (LocalStorage) ώστε να παραμένουν αποθηκευμένα (cached) ακόμα και μετά από ανανέωση ή κλείσιμο της σελίδας.

## Μελλοντικά Updates
Η δομή `app.js` έχει σχεδιαστεί με βάση το μοντέλο Model-View-Controller (MVC) για εύκολη μελλοντική προσθήκη:
- **Γραφημάτων:** Μπορείτε να εισάγετε εύκολα βιβλιοθήκες όπως το Chart.js.
- **Εξαγωγής Δεδομένων:** Προσθήκη λειτουργίας για PDF ή Excel/CSV exports.
- **Backend/Database:** Εύκολη προσαρμογή της συνάρτησης `saveState()` ώστε να στέλνει τα δεδομένα σε κάποιο API (π.χ. Firebase, Node.js/MongoDB) αντί για το LocalStorage.
